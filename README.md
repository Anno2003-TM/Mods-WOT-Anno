# Mods-WOT-Anno

Hitzone-Skins für World of Tanks – eine Erweiterung zu den Hitzone-Skins von **Emets** (PRO Tanki Skinner).
Sie ergänzt Skins für ca. 380 Panzer der Stufen IV–XI, die im Emets-Paket fehlen. Wie dort sieht man den Skin nur, wenn man einen Gegner anvisiert.

Markiert sind:
- Munitionslager (weiße Granaten)
- Kraftstofftank (roter Kasten mit Flamme)
- Motor (rotes Zahnrad)
- Besatzung (orange Icons)

## Download und Installation

1. Unter [Releases](https://github.com/Anno2003-TM/Mods-WOT-Anno/releases/latest) die Datei `Hitzone_Skins_Erweiterung_Installer.zip` laden.
2. Die Zip komplett entpacken und den Ordner behalten.
3. WoT schließen, `Hitzone_installieren.bat` starten und **1** wählen.

**Voraussetzung:** PRO Tanki Skinner mit den Hitzone-Skins von Emets muss installiert sein, z. B. über das Aslain-Modpack.

**Neue Version:** Starte den Installer und wähle **4**. Er lädt die neueste Version von hier und installiert sie. Wenn es eine neue Version gibt, siehst du das schon beim Start über dem Menü.

Nach einem Aslain-Update oder einem WoT-Patch startest du den Installer einfach noch einmal und wählst **1**.

Das ist ein rein optischer Mod. Nach der aktuellen Liste verbotener Mods von Wargaming (Stand Nov. 2026) ist er nicht verboten. Die Nutzung bleibt trotzdem auf eigene Verantwortung, denn Wargaming kann die Regeln jederzeit ändern.

Der Ordner `installer/` enthält die Skripte des Installers. Die fertige Zip mit den Skins gibt es nur unter Releases.
